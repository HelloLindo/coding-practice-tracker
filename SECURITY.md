# Security

This is a local single-user application. Keep the listener on `127.0.0.1`;
do not expose it through port forwarding, public tunnels, or a shared server.
Keep authentication outside the repository and review the problem text, code,
and notes sent to your own Codex CLI before using AI generation.

For a potential vulnerability, use this repository's GitHub **Security →
Report a vulnerability** option when available. If that option is unavailable,
open an issue asking the maintainer for a private reporting channel without
including exploit details, secrets, or affected personal data.

Include the affected revision, reproduction with synthetic data, and impact in
the private report. There is no guaranteed response or patch schedule.
